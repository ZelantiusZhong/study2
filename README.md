# Study 2｜价值表征与动态资源决策实验

这是一个可在本机独立运行的 Study 2 实验网站。界面采用接近 Study 1 的低干扰黑白风格；程序只使用复制到本项目内的刺激材料，不会读取、写入或修改桌面上的 Study 1 文件夹。

## 启动

双击 `启动Study2.command`，并在实验期间保持弹出的终端窗口开启。

- 首页：`http://127.0.0.1:3020`
- 被试入口：`http://127.0.0.1:3020/start`
- 研究者端：`http://127.0.0.1:3020/researcher`
- 被试入口密码：`Zx123456`
- 研究者密码：`Zx123456`

主试应在实验前按顺序准备被试编号（例如 `S2-001`、`S2-002`）并告知被试。数字尾号奇数进入稀缺组、偶数进入富足组；该规则只在研究者端显示。被试可凭同一编号断点续做。停止网站时，在终端按 `Control + C`。

## 正式流程

1. 入口密码、主试提供的被试编号、知情同意与被试登记。编号必须唯一并以数字结尾。
2. 实验开始前只测量即时心情、饥饿和昨晚睡眠质量；不在此处询问生活费，避免提前启动资源稀缺相关思考。
3. 4 次偏好选择练习。
4. Study 1 式两两比较校准：25 张抽象图形分为 5 个 set，每个 set 5 张；依次完成 50 次组内全配对、20 次相邻等级重测、0–40 次不一致项复测、20 次跨组中位锚定、20 次跨组高低锚定和 0–15 次自适应补测，共 110–165 次。
5. 同时计算 Elo 和 Bradley–Terry 潜在偏好值，最终保证每个 set 均有且仅有喜爱等级 1–5 各一张。
6. 45 次独立偏好验证，其中 30 次比较不同等级、15 次比较相同等级。不同等级一致率低于 85% 时，回到完整两两校准，并再次完成45次验证。
7. 呈现相对资源反馈，完成 6 次带真实正误反馈的资源任务练习。
8. 完成 90 次资源账户任务：72 次点数比较使用实验操纵反馈，18 次图形匹配使用真实反馈；每 5 次固定含 1 次真实反馈试次。第 45、90 次后分别填写阶段检查。
9. 完成 14 项操纵检验与任务体验问卷。
10. 学习每个图形的价格（5、10、15、20、25 代币）。价格采用拉丁方轮换：每个 set 内五档价格各一次，同一喜爱等级跨五个 set 也覆盖全部五档价格，避免喜爱、set 与价格混淆。随后完成 4 次购买练习和 4 题理解检查；理解检查必须全部正确才能进入正式任务。
11. 使用 1000 代币完成 80 次连续购买：购买 A、购买 B或本轮不购买。四类试次各 20 次：低冲突、喜爱—价格冲突、成本优势和预算压力。
12. 预算压力条件包含 10 组完全相同的物品对，每组在早期和晚期各出现一次，用于识别资源减少后的策略变化；左右位置反转以控制方位偏差。
13. 完成实验后目的、反馈可信度与怀疑度检查。
14. 在最后一页填写每月生活费总额、必要开支后可自由支配金额、充足感与经济压力，然后显示最终结果。

## 内置计算与质量控制

- 偏好稳定性：循环一致性、相邻重测、Kendall's W、Elo RMSE、split-half Spearman、漏答率和 A/B/C 综合稳定性等级。
- 连续选择：购买率、花费轨迹、资源效率、冲突选择、预算敏感性、重复配对切换、节约转变和冲突反应时减慢。
- 计算模型：喜爱单维、成本单维、静态整合、动态预算三选一 softmax；比较 AIC、BIC、五折交叉验证损失和预测准确率。
- 参数：喜爱权重 βL、代币边际价值 λ、预算交互、购买阈值 θ、每级喜爱愿付价格 WTP、选择一致性代理和决策熵。
- 顺序控制：成对比较和购买任务均平衡左右位置；关键重复试次强制左右反转。
- A/B 证据模型：以喜爱差、价格差和价格×预算压力预测左右选择。
- DDM/LBA：导出只含有效 A/B 选择的分析就绪表，包含秒制反应时、左右选择、喜爱差、价格差、动态价格压力和预算偏离。层级 DDM/LBA 应在收齐多名被试后离线拟合，网站不伪造单被试层级模型结果。
- 质量标记只用于主分析之外的敏感性分析，不会自动删除被试。
- 自动标记异常超快反应、超时、极端偏侧和缺失环节；后台显示九项关键阶段的数据完整度。
- 新登记会冻结协议版本和关键阈值；研究者端可识别正式 V3 记录与升级前的旧测试记录，避免不同程序版本混入同一分析。

详细变量解释和统计边界见 `实验与分析说明.md`；正式招募前逐项完成 `正式收数前检查清单.md`。

## 数据与导出

全部记录保存在 `data/study2-data.json`。写入时先保存临时文件再替换正式文件，以降低异常中断造成的数据损坏风险。

研究者端提供资源余额逐试次轨迹、购买率/剩余预算轨迹、操纵检验和分组质量表。可下载 14 类 CSV：被试汇总、偏好校准、偏好验证、资源任务、连续购买、刺激映射、计算模型、DDM/LBA、质量、完整性审计、图表聚合数据、问卷、事件和数据字典；另可下载包含所有原始记录的完整 JSON 主库备份。

正式收集前请备份空的 `data` 文件夹；每个实验日结束后再次离线备份。数据包含个人信息与行为记录，不应公开上传。
